# mitu-cicd

Практическая работа по дисциплине «Деплой и CI/CD».

## Инструкция по запуску

1. Установите node.
2. Клонируйте репозиторий или скачайте архив с исходным кодом.
3. В корне проекта запустите фронтенд: `cd frontend && npm install && npm run dev`
4. В корне проекта запустите бэкенд: `cd backend && npm install && node server.js`
